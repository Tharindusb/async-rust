Reference · Async Rust

Future

A value that represents async work. Built by calling an async fn; driven by .await on a runtime.

Picture

Sync call

Cook now.

call → body runs → done

Async call

Hand you a recipe (Future).

call → Future → .await → body runs

One line

Calling builds a Future; .await runs it. No .await → body never runs.

With Tokio

  • 1
    let op = say_world();

    Future created. Idle.

  • 2
    op.await;

    Runtime drives the Future. Body runs.

Do not confuse

  • A Future is not a thread. It is a value the runtime polls.
  • A Future is not TCP. TCP is the pipe; the Future is “wait for this step on the pipe.”
  • Deep poll / Pin details wait until the tutorial needs them (see mission out-of-scope).
