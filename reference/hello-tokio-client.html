Hello Tokio client

Two terminals: server listening, client awaiting connect / set / get.

Commands

cargo install mini-redis
mini-redis-server          # terminal A
cargo run                  # terminal B (this crate)

Shape

connect.await → set.await → get.await → print 

let mut client = client::connect("127.0.0.1:6379").await?;
client.set("hello", "world".into()).await?;
let result = client.get("hello").await?;

One line

Each async call builds a Future; each .await waits for that network step. Server must be up first.
