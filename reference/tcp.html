TCP

Private phone line between two programs. Handshake, then a reliable ordered byte stream. connect().await waits for this.

Picture

SYN → SYN-ACK → ACK → ESTABLISHED → SET / GET bytes

One line

TCP is not a thread and not a Future. The Future is “wait until this TCP step finishes.”

Do not confuse

  • IP carries packets; TCP turns them into an ordered stream.
  • Deep congestion control / sequence-number math waits until a later lesson needs it.
